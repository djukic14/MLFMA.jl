Phase

Box-centre phase shifting between levels.

MLFMA.Phase — Module
MLFMA.Phase

The phase a far field picks up when its reference point moves.

Defines phase factors, per-(level, sector) shifts, and level transfers that combine interpolation with phase. DummyPhaseShifter supplies unit phases for tests through the same transfer path.

MLFMA.Phase.DummyPhaseShifter — Type
DummyPhaseShifter()

A phase shifter that applies no phase at all.

Level transfers obtain unit phases through _phasesatlevel in interpolationphasecollection.jl. This type does not implement shifttoparentphase! or shifttochildphase!.

MLFMA.Phase.InterpolationPhaseTransfer — Type
InterpolationPhaseTransfer(interpolator, anterpolator, phase, childsampling, parentsampling,
                           interpolationtrait)

One MLFMA level transfer: interpolation from childsampling up to parentsampling, followed by the diagonal phase on the parent grid.

phase is the child sector's phase for this side, conjugated for the receive side. The constructor stores conjphase and the non-forward operators, so application does not rebuild them. For complex interpolation, two operators wrap a native apply with in-place conjugation of the moments. These passes allocate nothing but still cost time.

  • anterpolator – adjoint interpolation, applied in the adjoint direction alongside conjphase.
  • transposedinterpolator – plain transposed interpolation, applied in the transpose direction alongside phase. Identical to anterpolator for a real interpolation operator, and a distinct operator otherwise; MLFMA.transposedinterpolator decides which.
  • conjugatedinterpolator – conj(Interp), applied in the conjugate direction alongside conjphase. That direction is not a reversal (see the header), so this one runs child-to-parent like interpolator itself, and is interpolator for a real operator; MLFMA.conjugatedinterpolator decides.

Applied through H2Factory's level-transfer protocol, so the direction is chosen by the traversal, never here.

MLFMA.Phase.dotu — Method
dotu(u, v)

Return the unconjugated dot product, sum(u .* v). The phase exp(γ k̂ · r) uses a bilinear form. Using ⋅ would conjugate u instead.

Both phasefactor and the far-field kernel in beastfarfieldassembler.jl use this helper.

MLFMA.Phase.interpolationphasecollections — Method
interpolationphasecollections(phaseshifter, interpolator, anterpolator, samplings,
                              minrelevantlevel, levels, interpolationtrait; dims=3)

The (trial, test) pair of H2Factory.I2ITranslationCollections for MLFMA's level transfers.

Each stores one InterpolationPhaseTransfer per (child level, child sector), resolved by H2Factory's leveltransfer as transfers[level(tree, child)][transferkey(selector, ...)] – so the outer key is the child's own level and the inner key is its 1-based sector (H2Trees.sector is 0-based; SectorSelector's transferkey adds one).

phaseshifter supplies the per-level, per-sector phases, already on the parent grid. The trial collection stores them as-is (radiation convention) and the test collection stores their conjugates (receive convention).

Only levels strictly deeper than minrelevantlevel get transfers, matching PhaseShifter: a level transfer needs a parent, and the shallowest relevant level has none within range.

MLFMA.Phase.numberofsectors — Method
numberofsectors(tree) -> Int

Return the number of child sectors: 2^dimension, i.e. 8 for an octree and 4 for a quadtree.

The root centre's length gives the dimension through the tree wrapper interface, as in MLFMA.sampling. appendphaseshifts! stops visiting a level once every sector is recorded. This avoids redundant visits but has little effect on total construction time: on meshcircle(10.0, 1/40) (2514 functions, 284 nodes), visiting 9 rather than 267 nodes saved 1.5 µs out of 94.9 s.
