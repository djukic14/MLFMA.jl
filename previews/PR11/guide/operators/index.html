Supported operators

The operator chooses the far-field representation and component convention. Leaf storage is a separate choice.

Operator familyMoment representation
3-D Helmholtz single layerScalar
3-D Helmholtz double layersScalar
3-D Helmholtz hypersingularTwo spherical-vector groups
Maxwell single layerSpherical vector
Maxwell double layers and MLFMA.efieTangential spherical
MLFMA.MWHyperSingular3DScalar (radial projection)
2-D Helmholtz single and double layersScalar
2-D Helmholtz hypersingularTwo in-plane components and one scalar

Inspect the actual choice rather than inferring it from a component count:

MLFMA.farfieldtype(op)
MLFMA.farfieldstorerule(op)
MLFMA.interpolationtrait(op)

The first selects the layout, the second projects assembled values into it, and the third handles continuation of angular components at the poles.

Some double-layer operators lack a Galerkin mirrored-receive rule. Use an assembled Petrov receive side for these; inspect MLFMA.haslazyreceive(op) before choosing a Galerkin map for a new operator.

SHE and VSH storage require a tangential spherical operator. They are not storage options for every three-dimensional operator. Keep sampled storage for a native Maxwell single layer; choose an EFIE wrapper only when that is the operator you intend to assemble.

Circular harmonic storage supports the corresponding 2-D representations. See Leaf storage before choosing a compressed policy.
