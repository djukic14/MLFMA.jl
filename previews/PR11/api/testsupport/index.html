Test support

Fixtures and dummies used by the suite.

MLFMA.TestSupport — Module
MLFMA.TestSupport

Provides a deterministic far-field assembler for tests without performing quadrature. It uses Assembly's BoxFarFieldSampling and leafids, so Assembly must be loaded first. The unit-phase test shifter belongs to Phase.

source
MLFMA.TestSupport.DummyFarFieldAssembler — Type
DummyFarFieldAssembler{OperatorType,Space,QuadStrategyType,StoreRule,F,D}

A dummy far-field assembler for tests: it performs no quadrature, and instead fills every Fθ/Fφ entry with a deterministic value from dummyfarfieldvalue.

Values are deterministic and RNG-free, and vary across all three indices to expose collection errors.

Fields

  • operator: Used only for its scalar type.
  • space: Not used.
  • quadstrategy: Not used.
  • storerule: Not used – this assembler writes dummyfarfieldvalue blocks directly rather than going through H2Factory.buildstorer. Carried only so it mirrors BEASTFarFieldAssembler's shape and can be built by the same five-argument assembler-builder call.
source
MLFMA.TestSupport.DummyFarFieldAssemblerBuilder — Type
DummyFarFieldAssemblerBuilder()

The test counterpart of BEASTFarFieldAssemblerBuilder. Builds a DummyFarFieldAssembler from the same five arguments:

FarFieldStrategy(; assemblerbuilder=MLFMA.DummyFarFieldAssemblerBuilder())

Pass a builder instance, not the assembler type.

source
MLFMA.TestSupport.dummyfarfieldvalue — Method
dummyfarfieldvalue(T, component, samplepoint, basisfunction)

One deterministic pattern entry that varies with all three indices.

The pattern exposes transposes, swapped sample/basis axes and trial/test collection swaps. Complex T also makes missing conjugation visible; real T uses a real fallback. Values stay bounded on the scale of one to avoid extreme magnitudes during leaf aggregation.
