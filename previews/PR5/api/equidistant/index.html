Equidistant representation

An equidistant-in-both-angles representation with FFT and Lagrange backends.

MLFMA.Equidistant — Module
MLFMA.Equidistant

A far-field representation with equidistant θ and φ grids and two interchangeable interpolation backends. Its grid, quadrature, backends, and adjoints can be checked against analytic functions without a tree or assembler.

To use it in an MLFMA map:

IT = typeof(MLFMA.Equidistant.EquidistantInterpolator{ComplexF64}(FFTBackend()))
MLFMA.MLFMAStrategy(operator, X;
    samplingstrategy=MLFMA.SamplingStrategy(; samplingbuilder=EquidistantSamplingBuilder{Float64}()),
    leveltransferstrategy=MLFMA.LevelTransferStrategy(IT, phaseshifter))

The sampling builder and the interpolator family must agree – the interpolator errors at construction if handed a SphericalSampling, rather than failing at the first apply.

Both backends are allocation-free with matching scratch from MLFMA.interimscratch and fall back to their allocating reference paths without it.

Both backends use EquidistantSampling and the same spherical continuation:

  • FFTBackend – global spectral resampling. Exact (machine precision) for any field the grid resolves; unresolved content aliases.
  • LagrangeBackend – separable local tensor-product Lagrange. Algebraically convergent in stencil order and in oversampling; cheaper and local, but needs oversampling to be accurate.

The FFT backend needs a source grid that resolves the field's bandwidth. The Lagrange backend also needs oversampling for accurate local interpolation; increasing the stencil order reduces its error.

Quadrature uses exactquadratureweights, not the midpoint rule. The sphere's Jacobian becomes |sin θ| on the torus, whose kink prevents spectral convergence of the midpoint rule. exactquadratureweights integrates this factor analytically for resolved modes; see quadrature.jl.

MLFMA.Equidistant.EquidistantInterpolator — Type
EquidistantInterpolator{T}(backend; interpolationtrait=MLFMA.DefaultInterpolation())

Interpolation between two EquidistantSampling grids, in MLFMA's interpolator protocol, delegating to backend.

T is the moment element type. One type serves both backends because they differ only in the object that resample dispatches on – which is also what isrealinterpolation keys off, so the two families stay distinguishable where it matters without a second struct.

The stencilsize type parameter (MLFMA's, reported by MLFMA.stencilsize) is the Lagrange stencil order for LagrangeBackend and 0 for FFTBackend, 0 meaning "global – every source sample contributes". For an anisotropic LagrangeBackend{Pθ,Pφ} it is max(Pθ, Pφ): the protocol's slot holds one number, and the backend itself keeps both orders, so nothing is lost except in that one reported figure.

Each call selects parity through its interpolationtrait keyword, which defaults to the far field's defaultinterpolationtrait. The stored trait does not control an apply. Map constructors compare it with the operator's trait and reject a mismatch in component-sign conventions.

MLFMA.Equidistant.EquidistantInterpolator — Method
EquidistantInterpolator{stencilsize,T,B}(samplings, parentsamplings; interpolationtrait=...)

The construction shape the MAP CONSTRUCTORS use: interpolatortype(strategy) yields this type and calls it with the level-pair vectors.

The samplings are validated and then discarded. They catch grid mismatches at construction; per-level buffers, plans, and stencils belong to scratch, not to this interpolator. Both backends are singletons, so the backend is recovered from B rather than passed.

MLFMA.Equidistant.EquidistantSampling — Type
EquidistantSampling{T}(Nθ, Nφ)

Equidistant sampling in BOTH angular coordinates: a midpoint θ grid on (0, π) and the usual equidistant φ grid on [0, 2π).

θᵢ = (i - 1/2)·π/Nθ    i = 1 … Nθ        (midpoint: no sample at either pole)
φⱼ = 2π(j - 1)/Nφ      j = 1 … Nφ        (`Nφ` even, so φ → φ+π is a half-array shift)

This is the grid; the interpolation ALGORITHM is a separate choice – see FFTBackend and LagrangeBackend, both of which consume this same object and this same continuation rule.

MLFMA.Equidistant.LagrangeStencils — Type
LagrangeStencils(p, positions)

The p-point Lagrange stencil at every entry of positions, precomputed.

positions[i] is target i's location in SOURCE cells (0-based), and lefts[i] is the resulting first stencil node – possibly out of range at either end, which sphericalget and φ periodicity resolve exactly as they do on the allocating path.

source
MLFMA.Equidistant.LagrangeTranspose — Type
LagrangeTranspose(stencils, ncoarse)

The φ stencils TRANSPOSED: for every coarse φ row, the fine rows that scatter into it and with what weight, in CSR form.

The adjoint's φ stage could scatter with out[index[b,j′], i] += w * v. Reversing that map makes it a gather: each output cell accumulates in a register and is written once.

ORDER IS PRESERVED, so this stays bitwise. The scatter visits (j′, b) in ascending order and each (j′, b) reaches its destination once, so a destination cell accumulates in ascending (j′, b). This constructor fills each bucket in that same order, so the summation order per output cell is identical. The θ stage's reorder does not preserve summation order: its shifts make the arrival order depend on the column. That stage can therefore differ from the reference by round-off.

source
MLFMA.Equidistant.ReflectedStencils — Type
ReflectedStencils(p, positions, nθ, nφ)

The θ stencils with the SPHERICAL CONTINUATION ALREADY RESOLVED: for every tap, the physical row it reads, the φ half-turn it needs, and the sign it carries.

Cache the reflection so the θ loop need not call sphericalget for each tap. reflectindex(i, j, Nθ, Nφ) depends only on the grid and indices, not on the data.

TWO THINGS FOLD OUT, both of which keep the inner loop free of branches:

  • The φ dependence is a PURE ADDITIVE SHIFT, so probing reflectindex at j = 1 gives the offset for every j. Each reflection adds Nφ÷2, so the offset is 0 or Nφ÷2 and nothing else.
  • The sign is (-1)^reflections and multiplication by ±1 is EXACT, so folding it into a second weight table costs no accuracy: w * (sgn * v) and (w * sgn) * v are the same Float64. That is what keeps this bitwise against the allocating reference, and it is the only reason the sign may leave the inner loop.

MLFMA.Equidistant.exactquadratureweights — Method
exactquadratureweights(sampling) -> Matrix

Weights W such that sum(W .* F) equals ∮ F dΩ EXACTLY for every F band-limited to the grid, where F is stored on the physical grid with φ as the first axis and θ as the second.

Exact for θ-modes up to Nθ - 1 and all φ-modes the grid resolves. Contrast quadratureweights, which is the plain midpoint rule and only O(h²) – see this file's header for why the sphere's Jacobian costs the midpoint rule its spectral accuracy.

MLFMA.Equidistant.quadratureweights — Method
quadratureweights(sampling)

Product midpoint weights for ∫ F dΩ = ∫∫ F sinθ dφ dθ:

w[j, i] = Δθ · Δφ · sin(θᵢ),    Δθ = π/Nθ,  Δφ = 2π/Nφ.

Separate from anything interpolation does. Quadrature error and interpolation error are different error sources and are tested apart; this is also the sinθ that stops spectral restriction and the weighted adjoint of interpolation from coinciding (see adjointinterpolate!).

source
MLFMA.Equidistant.reflectindex — Method
reflectindex(i, j, Nθ, Nφ) -> (i′, j′, sign)

Map a θ index OUTSIDE 1:Nθ back onto the physical grid, returning the partner index pair and (-1)^reflections – the factor an ANTI-spherical component picks up. A spherical one picks up 1 whatever the count, since each reflection leaves it unchanged.

Both poles reduce to the same two operations – reflect θ, half-turn φ – because the midpoint grid has no sample sitting on either pole to special-case:

i < 1   (θ < 0)  ->  i′ = 1 - i,          φ → φ + π
i > Nθ  (θ > π)  ->  i′ = 2Nθ + 1 - i,    φ → φ + π

A stencil reaching more than a full grid past a pole reflects repeatedly, and the sign accumulates; the loop is written out rather than assumed away, because p is a caller's choice and Nθ shrinks with the tree level.

MLFMA.Equidistant.resampleadjoint! — Method
resampleadjoint!(out, Y, coarse, fine, parity, ::FFTBackend, scratch) -> out

resampleadjoint on the reduced θ grid, with every temporary taken from scratch. Allocates nothing once warmed up.

As in the allocating form, the samplings name the FORWARD direction: coarse first, then fine, while the data flows fine -> coarse.

DERIVED STAGE BY STAGE FROM resample!, reversing the chain and transposing each link. The two links worth stating, because neither is guessable and both are off-by-a-factor-of-two traps:

(REDFT10)ᵀ = REDFT01 ∘ diag(2,1,…,1)      (RODFT10)ᵀ = RODFT01 ∘ diag(1,…,1,2)
(REDFT01)ᵀ = diag(1/2,1,…,1) ∘ REDFT10    (RODFT01)ᵀ = diag(1,…,1,1/2) ∘ RODFT10

FFTW's DCT-III is the transpose of its DCT-II only up to the first coefficient, which the III form weights by 1 where the transpose wants 2; the sine pair has the same discrepancy at the LAST coefficient instead. Everything else transposes into itself: the pack and unpack permutations swap, and the head copy becomes a truncation with the same boundary factor.

source
MLFMA.Equidistant.resamplecoefficients — Method
resamplecoefficients(Ĝ, Nsrc, Ndst) -> Ĝ′

Move normalized DFT coefficients from a length-Nsrc grid to a length-Ndst one, matching SIGNED frequencies. Padding (Ndst > Nsrc) is interpolation; truncation (Ndst < Nsrc) is an ideal spectral low-pass, which is the anti-aliasing filter a restriction needs – there is no separate filter step.

THE NYQUIST BIN IS SPLIT IN HALF between +N/2 and -N/2 when upsampling an even-length transform, and the two halves are recombined when downsampling. That single bin is genuinely ambiguous in sign, and splitting it is the choice that makes the result the band-limited trigonometric interpolant rather than one arbitrarily-rotated cousin of it. By construction MLFMA keeps content well below Nyquist (Nθ ≥ L+1, Nφ ≥ 2(L+1)), so this bin should be negligible – but "should be negligible" is a reason to handle it correctly and cheaply, not a reason to guess.

MLFMA.Equidistant.resamplereflectedcoefficients — Method
resamplereflectedcoefficients(Ĝ, Nsrc, Ndst) -> Ĝ′

resamplecoefficients for a sequence living on a HALF-SAMPLE-REFLECTED torus – which θ always is, and which φ never is.

The top bin is a sine mode, not a symmetric pair. resamplecoefficients splits it evenly across ±N/2, which reconstructs a COS mode; on a reflected torus that mode is identically zero at every sample (cos(π(n+1/2)) == 0), so the content actually sitting in the bin is the SIN mode and an even split would reconstruct a different function. Negate the half landing on -N/2 when upsampling, and subtract the two source halves when downsampling. This preserves the torus reflection even when the top bin contains data.

CALLERS MUST PASS TRUE FOURIER COEFFICIENTS, not midpoint-convention ones. This routine moves content BETWEEN frequencies, so a phase attached per SOURCE frequency would follow that content to the wrong destination. resample divides the source convention out before the move and applies the destination's after it, for this reason.

MLFMA.Equidistant.resamplereflectedcoefficientsadjoint — Method
resamplereflectedcoefficientsadjoint(v, Nsrc, Ndst) -> length-`Nsrc` vector

Its coefficients are ±1 and ±1/2 – all real – so transpose and adjoint coincide here too. The reflected top bin retains its signs: the up-split transposes into a difference of the two half-bins, and the down-fold returns the destination top bin negated to the negative source frequency.

MLFMA.Equidistant.sphericalget — Method
sphericalget(F, i, j, sampling, parity) -> value

Read F[j, i] – θ index i, φ index j – for ANY integer index pair, applying the continuation of reflectindex and the sign for a component of the given parity (SPHERICAL or ANTISPHERICAL).

This is the accessor the Lagrange stencils index through, so the stencil code itself never mentions a pole. It is also the reference the FFT extension is tested against – the same rule reached two ways.

MLFMA.Equidistant.sphericalhankel1 — Method
sphericalhankel1(L, x) -> Vector

h_l⁽¹⁾(x) = j_l(x) + i y_l(x) for l = 0:L, by upward recurrence.

Upward recurrence is unstable for j_l but STABLE for h_l⁽¹⁾, whose magnitude grows with l – the direction of growth is what makes the recurrence well conditioned here.

MLFMA.Equidistant.sphericalscatter! — Method
sphericalscatter!(F, v, i, j, sampling, parity)

Accumulate v into F at the physical partner of the (possibly out-of-range) index (i, j), where i is the θ index and j the φ index. F is stored [φ, θ] like every other sampled array.

The exact adjoint of sphericalget: same reflection, same sign, += instead of read. The sign is real, so this serves the transpose and the adjoint alike.

The unit direction and the integration weight at every grid point, both Nφ × Nθ.

The weights come from exactquadratureweights, not the midpoint rule. They account analytically for the torus Jacobian |sin θ|; sampling that factor would give only algebraic convergence.

MLFMA.Sampling.cutoffparameter — Method
cutoffparameter(s::EquidistantSampling) -> Int

The design degree inferred from the θ count, using the inverse of the standard rate rule.

MLFMA.NθNφ(L) returns (2(L+1), 4(L+1)) to resolve products of degree-L patterns, whose bandwidth reaches 2L. exactquadratureweights integrates θ modes through Nθ - 1, so the θ requirement is 2L ≤ Nθ - 1. A hand-built grid must also provide enough φ samples; this accessor checks neither its φ count nor the field's bandwidth.

MLFMA.Sampling.mirrorindices — Method
mirrorindices(sampling) -> Matrix{Int}

Linear indices realizing the ANTIPODAL map k̂ → -k̂, i.e. (θ, φ) → (π - θ, φ + π), so that F[mirrorindices(s)] samples f(-k̂) wherever F samples f(k̂).

EXACT on this grid, with no interpolation and no special case. Note this is a DIFFERENT map from the torus continuation (2π - θ, φ + π) used by reflectindex: the antipode reflects about the EQUATOR and never goes near a pole, so the absence of pole samples is irrelevant to it. The midpoint grid is symmetric under both halves of it:

π - θᵢ = π - (i - 1/2)π/Nθ = ((Nθ - i + 1) - 1/2)·π/Nθ = θ_{Nθ+1-i}
φⱼ + π = φ_{j + Nφ/2}                          (`Nφ` even is enforced at construction)

MLFMA.Sampling.supportedsymmetry — Method
supportedsymmetry(s::EquidistantSampling)

The same symmetry policy as SphericalSampling: the 16-element subgroup preserving the polar axis when Nφ is divisible by four, and the smaller antipodal group otherwise.

The action requires exact index maps for θ → π - θ and φ → σφ + β. The uniform φ grid supports quarter-turns when Nφ is divisible by four. The midpoint θ grid supports reversal because

θᵢ + θ_{Nθ+1-i} = (i - ½)π/Nθ + (Nθ - i + ½)π/Nθ = π

Thus π - θᵢ == θ_{Nθ+1-i} in exact arithmetic. The action reverses indices rather than subtracting stored angles. Combined with φ → φ+π, this is the antipodal map, not continuation across a pole.

The full 48-element lattice group is not supported: elements that move the polar axis into the equatorial plane need not map this product grid onto itself.
