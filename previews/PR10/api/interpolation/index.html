Interpolation

Interpolation and anterpolation between adjacent levels' direction grids.

MLFMA.Interpolation — Module
MLFMA.Interpolation

Moving a far field between the angular sampling rates of two levels, in both directions.

Owns the interpolation traits, the interpolator and anterpolator families and their per-level-pair information caches, the transposed and conjugated wrappers, the interim scratch, the builders that select a family, and the diagnostics submodule.

It depends on Sampling for grids and angular rates, and on FarFields for field representations. It does not depend on assembly or tree traversal.

interpolationtrait and interpolatortype are owned here and extended higher up, by Operators and by the assembly strategies. Both are imported at the top level for that reason.

MLFMA.Interpolation.CircularAnterpolator — Type
CircularAnterpolator(interpolator)

The ADJOINT of a CircularInterpolator – Rᴴ, bare, with no quadrature weights.

Shares the interpolator's CircularInterimScratch: interpolation runs child → parent and anterpolation parent → child, so between them they need exactly the two spectra it holds.

source
MLFMA.Interpolation.CircularAnterpolator — Method
(anterpolator::CircularAnterpolator)(anterpolatedfarfield, farfield, farfieldsampling,
                                     anterpolationsampling; interpolationtrait, interim,
                                     prescale, stagetransform)

Apply the adjoint of interpolation, taking farfield on the PARENT grid farfieldsampling down to the CHILD grid anterpolationsampling.

prescale and stagetransform carry the same meaning as in the other families and go through the same Interpolation._stageprescaled!: apply the diagonal and transform while copying into the private parent spectrum. The caller's moment is never mutated, so concurrent children can read it. Without prescale, the copy applies no stagetransform.

MLFMA.Interpolation.CircularInterimScratch — Type
CircularInterimScratch(childsampling, parentsampling, T)

One level pair's worth of spectral scratch: the two working spectra and four IN-PLACE FFT plans.

There is deliberately no staging vector for prescale. Both directions copy their input into a spectrum buffer before transforming it, so the anterpolator's diagonal is applied during a copy that had to happen anyway – unlike the LocalθGlobalφ family, which transforms the caller's array in place and therefore needs a private copy to stage into.

Built per (level, chunk) by MLFMA.Interpolation.interimscratch rather than stored on the interpolator, so each concurrent task owns its own plans and buffers. That is the same arrangement Equidistant.FFTScratch has, for the same reason: the interpolator lives on the read-only core, and a plan applied in place is not something two chunks may share.

Both directions of the pair are served by one object – interpolation runs child → parent and anterpolation parent → child, so between them they need exactly these two spectra.

MLFMA.Interpolation.CircularInterpolationBuilder — Type
CircularInterpolationBuilder(; T=ComplexF64)

Build the circular family: spectral resampling between two CircularSampling grids, for 2-D problems.

NO ORDER KEYWORD, and that is a property of the method rather than an omission. The step is a global spectral resample, exact for anything the source grid resolves, so there is no stencil whose size trades accuracy against cost – its order parameter is fixed at 0, MLFMA's spelling for "global: every source sample contributes".

Its operator is REAL (see MLFMA.isrealinterpolation), so its anterpolator serves both reverse directions and buildreverseoperators returns the same object twice.

source
MLFMA.Interpolation.CircularInterpolator — Type
CircularInterpolator{T}(; interpolationtrait=DefaultInterpolation())
CircularInterpolator{0,T}(samplings, parentsamplings; interpolationtrait=...)

Spectral interpolation between two CircularSampling grids, in MLFMA's interpolator protocol.

Exact for any pattern the source grid resolves: the residual is floating point, not truncation. The stencilsize parameter is 0, meaning global – every source sample contributes to every destination sample, so there is no order to choose.

The second form is the shape the MAP CONSTRUCTORS use (interpolatortype(strategy) yields the type and calls it with the level-pair vectors). The samplings are validated and then discarded: this family caches nothing per level pair, so the pairs serve only to catch a grid mismatch at construction rather than at the first apply. Its FFT plans live in the per-(level, chunk) scratch instead – see MLFMA.Interpolation.interimscratch – so concurrent chunks never share one.

The stored interpolationtrait is used for construction checks, not apply-time arithmetic. Map constructors compare it with the operator's trait and reject a mismatch. Each call checks the per-call trait's arity, then applies the same resampling to every component.

MLFMA.Interpolation.CircularInterpolator — Method
(interpolator::CircularInterpolator)(interpolatedfarfield, farfield, farfieldsampling,

Resample every component of farfield from farfieldsampling onto interpolationsampling, writing into interpolatedfarfield.

postscale, when given, is a diagonal applied to the result in the same pass that writes it – the same fused contract the other families offer, so a level transfer's phase costs no extra sweep.

source
MLFMA.Interpolation.ConjugatedInterpolator — Type
ConjugatedInterpolator(interpolator)

The CONJUGATE of an interpolation operator, conj(I), built from the interpolator itself.

Applies $conj(I) = conj ∘ I ∘ conj$. Conjugated but NOT transposed – distinct from both TransposedInterpolator and an anterpolator, and the direction an ADJOINT map's aggregation applies. See conjugatedinterpolator, which returns the interpolator unchanged when its operator is real.

The conjugations are done IN PLACE and the input is restored before returning, from a finally, so it happens even when the wrapped interpolator throws. An apply allocates nothing beyond what the wrapped interpolator allocates. As with TransposedInterpolator, the restore is only as faithful as the wrapped operator: a family that perturbs its input on an FFT round trip returns it to round-off, not bitwise.

MLFMA.Interpolation.DefaultInterpolation — Type

Resolve the trait from the far-field representation through defaultinterpolationtrait.

Scalar fields use VirtualExtension, tangential spherical fields use SphericalθφInterpolation, spherical vector fields use SphericalInterpolation, and paired spherical vector fields use DoubleSphericalInterpolation. Planar vector-scalar fields use PeriodicφInterpolation{3}. The component count alone does not determine the continuation rule.

MLFMA.Interpolation.GaussLegendreInterpolationInformation — Type
GaussLegendreInterpolationInformation{stencilsize,T1}

Precomputed θ stencils and weights for one (source, target) Gauss-Legendre θ grid pair, shared by both interpolator families: the Lagrange kernel in sphericalinterpolation.jl and the global-φ kernel in localglobalinterpolation.jl dispatch on this same type. A change to any field here has to be checked against both.

Both kernels read the same fields in the same order. The row-writing family stages through a contiguous vector; it does not need different stencil storage. test/LevelTransfers/interpolation.jl checks both kernels against one shared information object.

Ranges and plain Vector weights let the θ products use the fast mul! kernel:

  • Vector{Int} column indices make view(fvals, :, indices) non-strided, forcing LinearAlgebra's generic path. The extending sets are therefore stored as spanning UnitRanges with their weights zero-padded across any gap (see MLFMA.spanningranges).
  • SVector{stencilsize,T1} weights also miss this fast path; use Vector{T1} weights instead.

An EMPTY extending range (1:0) means "this target θ takes no extended contribution". isassigned cannot express that once the storage is a bits type, so the kernels test isempty instead.

MLFMA.Interpolation.LevelTransferScratch — Type
LevelTransferScratch(parentmoment, childmoment, interim)

One chunk's worth of level-transfer scratch, borrowed per (level, chunk) by H2Factory's traversal and reached through context.buffer in H2Factory.applydirectedtransfer!.

  • parentmoment – a moment on the PARENT direction grid. The forward transfer stages through it when accumulating; the reverse directions always need it, since the diagonal phase acts on the parent grid.
  • childmoment – a moment on the CHILD grid, or nothing. Only the accumulating reverse direction needs it, so the I2I side leaves it empty.
  • interim – the interpolator/anterpolator's own interim arrays for this level pair, built by interimscratch, or nothing to let them allocate per call.

MLFMA.Interpolation.LocalθGlobalφInterpolationBuilder — Type
LocalθGlobalφInterpolationBuilder(; θorder, T=ComplexF64)

Build the local-θ, global-φ family: local interpolation in θ, an FFT in φ.

θorder controls the local θ stencil. The φ step is global and has no stencil order; it evaluates the Fourier interpolant to round-off for resolved content away from the Nyquist ambiguity.

Its operator is COMPLEX, so its anterpolator (adjoint interpolation) and its transposed interpolation are different operators; buildreverseoperators returns both.

MLFMA.Interpolation.PeriodicφInterpolation — Type
f(φ) = f(φ + 2π)

Periodic continuation for N components on a circle. There is no θ coordinate or pole reflection, so every component uses the same rule without a sign change.

Unlike VirtualExtension, this trait does not describe a spherical pole rule. There are no conversions to spherical traits or entries in Equidistant.componentparities; those families reject it rather than apply a rule for the wrong geometry. The circular interpolator checks only its arity.

MLFMA.Interpolation.TransposedInterpolator — Type
TransposedInterpolator(anterpolator)

The plain TRANSPOSE of an interpolation operator, built from its adjoint (an anterpolator).

Applies $I^T = conj ∘ I^H ∘ conj$, which is exact rather than approximate: with $I^H = conj(I^T)$, conjugating on both sides of the adjoint recovers the transpose identically. Only needed for families where the two differ – see transposedinterpolator, which returns the anterpolator itself when the operator is real.

With prescale, the wrapped anterpolator stages and conjugates the scaled input in private scratch; the caller's moment is untouched. Without it, this wrapper conjugates the input in place and undoes that conjugation in finally, even if the wrapped call throws. This unscaled path requires exclusive access to the input during the call.

The wrapper adds no allocations. Double conjugation is exact, but a wrapped FFT round trip may perturb the restored input by round-off. The wrapper cannot undo those changes or other mutations made by a failing wrapped operator.

source
MLFMA.Interpolation.VirtualExtension — Type
f(θ,φ) = f(θ,φ+2π),     for φ < 0
f(θ,φ) = f(θ,φ-2π),     for φ > 2π

f(θ,φ) = f(-θ,φ+pi),    for θ< 0, 0 < φ < π
f(θ,φ) = f(-θ,φ-pi),    for θ < 0, π < φ < 2π
f(θ,φ) = f(2π-θ,φ+pi),  for θ > π, 0 < φ < π
f(θ,φ) = f(2π-θ,φ-pi)   for θ > π, π < φ < 2π

Continue a scalar across either pole without changing its sign. Wrap φ periodically before applying the pole rule; at φ = 0 or φ = π, use the same half-turn modulo 2π. These reflections preserve the physical direction, unlike the antipodal map (π-θ, φ+π).

MLFMA.Interpolation.VirtualExtensionFlipθSign — Type
f(θ,φ) = f(θ,φ+2π),     for φ < 0
f(θ,φ) = f(θ,φ-2π),     for φ > 2π

f(θ,φ) = -f(-θ,φ+pi),    for θ < 0, 0 < φ < π
f(θ,φ) = -f(-θ,φ-pi),    for θ < 0, π < φ < 2π
f(θ,φ) = -f(2π-θ,φ+pi),  for θ > π, 0 < φ < π
f(θ,φ) = -f(2π-θ,φ-pi)   for θ > π, π < φ < 2π

Use the same periodic wrapping and pole reflections as VirtualExtension, but negate the component at each pole crossing. Wrapping φ alone does not change the sign.

MLFMA.Interpolation._interpolationweights — Method
_interpolationweights(barycentricweights, samples, newsample)

The barycentric Lagrange weights evaluating an interpolant at newsample.

Second-form barycentric interpolation: wᵢ / (x - xᵢ), normalized by its own sum. samples are the nodes, barycentricweights their precomputed barycentric weights.

Handles the exact-hit case explicitly. If newsample coincides with a node the reciprocal is infinite, so the result is the corresponding unit vector instead: the interpolant reproduces the sample there. Without that branch the formula would produce Inf/Inf.

MLFMA.Interpolation._movecircularcoefficients! — Method
_movecircularcoefficients!(ĝ′, ĝ, Nsrc, Ndst) -> ĝ′

Move DFT coefficients from a length-Nsrc grid to a length-Ndst one, matching SIGNED frequencies, writing into a caller-owned ĝ′ which it ZEROES first.

Padding (Ndst > Nsrc) is interpolation; truncation (Ndst < Nsrc) is an ideal spectral low-pass, which is the anti-aliasing a restriction needs – there is no separate filter step. The source Nyquist bin is split evenly across ±N/2 going up and folded back coming down; see this file's header for why that bin is handled at all when MLFMA's own rate rule keeps it empty.

The zeroing is not the caller's job: the += accumulation is what makes the split work, so a caller that forgot would pick up the previous component's contents.

source
MLFMA.Interpolation._movecircularcoefficientsadjoint! — Method
_movecircularcoefficientsadjoint!(x̂, ŷ, Nsrc, Ndst) -> x̂

The exact TRANSPOSE of _movecircularcoefficients!: consumes length-Ndst coefficients and produces length-Nsrc ones, with Nsrc/Ndst still naming the FORWARD direction.

Written as an assignment per source bin rather than an accumulation, because the transpose of a map that sends each source bin to one or two destinations is a gather. Dropped bands assign zero explicitly, which is what makes this a total transpose rather than one that leaves stale content in the truncated modes.

The move's weights are real, so no conjugation appears here and this is Pᵀ = Pᴴ – which is what makes the anterpolator built on it the exact adjoint of the interpolator.

MLFMA.Interpolation.interimscratch — Method
interimscratch(anterpolator, childsampling, parentsampling)

Build the interim arrays one level transfer between childsampling and parentsampling needs, as a NamedTuple whose fields the interpolator and anterpolator read through takeinterim.

Dispatches on the anterpolator, which stores its interpolator and needs at least as much scratch. One method per family covers both directions. The fallback returns nothing, so families without a scratch method allocate their interim arrays per call.

The shapes follow from which sampling plays which role in each direction. Interpolation runs child -> parent (farfieldsampling = childsampling, interpolationsampling = parentsampling) and anterpolation runs parent -> child, so both stage through an interim grid mixing the parent's Nθ with the child's Nφ, and one set of arrays serves both directions.

MLFMA.Interpolation.mulrotatedrows! — Function
mulrotatedrows!(result, fvals, indices, weights, α=true, β=false)

result = view(fvals, flippingφindices, indices) * weights, computed as two contiguous row blocks instead of one permuted view.

flippingφindices is always vcat(Nφ÷2+1:Nφ, 1:Nφ÷2) – a rotation by half the φ count, which is why it never has to be passed in: the rotation is recovered from size(fvals, 1), and SphericalSampling guarantees an even Nφ.

The permutation makes the view non-strided. Two contiguous blocks let mul! use its fast path:

y[1:half]        = fvals[half+1:2half, indices] * weights
y[half+1:2half]  = fvals[1:half,       indices] * weights

The fast path may sum in a different order from the permuted form. Compare results with isapprox, not bitwise equality.

α and β are mul!'s scaling factors, so an accumulating caller passes (true, true): the interpolator's extending branch adds its mirrored contribution onto a column the positive branch already wrote.

MLFMA.Interpolation.spanningranges — Method
spanningranges(sets, weightsets, ::Type{T})

Convert push-built index sets and their weights into (ranges, paddedweights), where each range spans its set and the weights are zero-padded across any gap.

Shared by the interpolation and anterpolation information constructors – both build their θ index sets by pushing, and both feed them to a mul! that wants a strided column index.

Unassigned or empty entries become 1:0, the empty range – how the θ kernels recognise "this child θ receives nothing", since isassigned cannot do that once the storage holds a bits type.

The sets may have gaps because the constructors skip zero weights. Padding those gaps with zeros preserves the weighted sum and gives every entry a UnitRange. This keeps the column view strided and lets mul! use its fast kernel without a union of index types.

How many far-field components trait describes.
