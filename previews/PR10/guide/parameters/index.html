Choosing parameters

Start with MLFMA.MLFMAStrategy(op, X). Override a sub-strategy to change one part of construction.

ChangePass to MLFMAStrategyWhat it controls
Angular resolutionsamplingstrategy=MLFMA.SamplingStrategy(op; ϵ=1e-4)Grid resolution from tolerance and box size
Support outside a boxsamplingstrategy=MLFMA.SamplingStrategy(op; protrusionaware=true)Includes measured basis-support extension
Leaf sizetreestrategy=MLFMA.TreeStrategy(op; minhalfsize=λ/4)Minimum box half-side length
Leaf storagefarfieldstrategy=MLFMA.FarFieldStrategy(; leafstorage=MLFMA.VectorSphericalHarmonicLeafStorage())Sampled or compressed collections
Angular transferleveltransferstrategy=MLFMA.LevelTransferStrategy(op, builder)Interpolation family and stencil
Translation symmetryi2ostrategy=MLFMA.I2OTranslationStrategy(; TranslationCollection=MLFMA.SymmetryTranslationCollection)Reuses symmetry-related I2O arrays

ϵ guides angular sampling and harmonic truncation. It is not a bound on the final matrix error: quadrature, leaf size and interpolation also contribute.

Interpolation builders

builder = MLFMA.LocalθGlobalφInterpolationBuilder(; θorder=15)
transfer = MLFMA.LevelTransferStrategy(op, builder)
strategy = MLFMA.MLFMAStrategy(op, X; leveltransferstrategy=transfer)

Use MLFMA.SphericalLagrangeInterpolationBuilder(; order=15) for local interpolation in both angles. Operator-aware defaults choose circular interpolation for 2-D. A builder's element type must match γ(op); set its T keyword for another precision or a real γ.

Assembly quadrature

Far-field quadrature goes into MLFMA.FarFieldStrategy(; quadstrategy=...). Near-field quadrature goes into MLFMA.SparseBEASTNearInteractionsStrategy(quadstrategy), passed as nearinteractionsstrategy. These integrate basis functions; they are separate from angular quadrature on the sphere.

For workspace reuse and parallel execution, see H2Factory.
