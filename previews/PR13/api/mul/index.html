Moment multiplication

Multiplication methods for far fields and their sampled collections.

LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::MLFMA.FarFields.ScalarFarField{D,T1}, momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * y, for i in 1:D

Arguments

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MLFMA.FarFields.ScalarFarField{2,Float64}((10,))
mcol = MLFMA.FarFields.ScalarRadiationFieldCollection{2,Float64}((10, 10))
y = zeros(Float64, 10)

LinearAlgebra.mul!(m, mcol, y)

Returns

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: The updated moment after multiplication.
source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::MLFMA.FarFields.ScalarFarField{D,T1}, momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MLFMA.FarFields.ScalarFarField{2,Float64}((3, 3))
mcol = MLFMA.FarFields.ScalarRadiationFieldCollection{2,Float64}((9, 9))
y = ones(Float64, 9)

LinearAlgebra.mul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: The updated moment.
source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(result::AbstractArray{<:Number}, momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}, moment::MLFMA.FarFields.ScalarFarField{D,T1})

Transpose operation to LinearAlgebra.mul!(moment, momentcollection, result). If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

result .= 0
result += transpose(momentcollection[i]) * moment[i], for i in 1:D

Arguments

  • result::AbstractArray{<:Number}: An abstract array of numbers.
  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}: A momentcollection.

Example

m = MLFMA.FarFields.ScalarFarField{2,ComplexF64}((10,))
mcol = MLFMA.FarFields.ScalarRadiationFieldCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

LinearAlgebra.mul!(y, mcol, m)

Returns

  • result::AbstractArray{<:Number}: Updated array after the multiplication.

Transpose operation to LinearAlgebra.mul!(moment, momentcollection, result). If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product
