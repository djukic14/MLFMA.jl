Conjugated moment multiplication

Conjugated multiplication methods used by reversed products.

H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::MLFMA.FarFields.ScalarFarField{D,T1}, momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * conj(y), for i in 1:D

Arguments

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MLFMA.FarFields.ScalarFarField{2,ComplexF64}((10,))
mcol = MLFMA.FarFields.ScalarRadiationFieldCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

H2Factory.conjmul!(m, mcol, y)

Returns

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: The updated moment after conjugate multiplication.
source
H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::MLFMA.FarFields.ScalarFarField{D,T1}, momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.ScalarRadiationFieldCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MLFMA.FarFields.ScalarFarField{2,ComplexF64}((3, 3))
mcol = MLFMA.FarFields.ScalarRadiationFieldCollection{2,ComplexF64}((9, 9))
y = Array(1:9) * im

H2Factory.conjmul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::MLFMA.FarFields.ScalarFarField{D,T1}: The updated moment after conjugate multiplication.
source

conjmul!(moment::MLFMA.FarFields.PairedSphericalVectorFarField{D,T1}, momentcollection::MLFMA.FarFields.PairedSphericalRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * conj(y), for i in 1:D

Arguments

  • moment::MLFMA.FarFields.PairedSphericalVectorFarField{D,T1}: A moment.
  • momentcollection::MLFMA.FarFields.PairedSphericalRadiationFieldCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MLFMA.FarFields.PairedSphericalVectorFarField{2,ComplexF64}((10,))
mcol = MLFMA.FarFields.PairedSphericalRadiationFieldCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

H2Factory.conjmul!(m, mcol, y)

Returns

  • moment::MLFMA.FarFields.PairedSphericalVectorFarField{D,T1}: The updated moment after conjugate multiplication.

conjmul!(moment::MLFMA.FarFields.PairedSphericalVectorFarField{D,T1}, momentcollection::MLFMA.FarFields.PairedSphericalRadiationFieldCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

mcol = MLFMA.FarFields.PairedSphericalRadiationFieldCollection{2,ComplexF64}((9, 9))
y = Array(1:9) * im

H2Factory.conjmul!(m, mcol, y, 1.0, 2.0)
