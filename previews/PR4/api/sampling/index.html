Sampling

Direction samplings over the sphere and the circle, and the cutoff relation NθNφ/cutoffparameter that sizes them.

MLFMA.Sampling — Module
MLFMA.Sampling

The angular grids a far field is represented on, and how a lattice symmetry acts on them.

Defines spherical product grids and circular grids, their builders, sample points, quadrature weights, mirror indices and symmetry permutations. It has no dependencies on other MLFMA modules. Its exports are also available as MLFMA.name.

source
MLFMA.Sampling.AbstractSampling — Type
AbstractSampling{T<:Number}

A set of sampling directions on which a far field is represented, together with the quadrature weights that integrate over them.

The layout may be a θ×φ product grid (see AbstractSphericalSampling), a set of rings, or a one-angle circle. Generic far-field containers, phases and collection builders use this interface.

Type parameters

  • T: the element type of the sampling points. Real even when the operator is complex – the grid is geometry, not field data.

Required interface

A concrete sampling must provide:

  • Base.length(s): the number of directions.
  • Base.size(s): the shape of an array holding one scalar per direction. May be any tuple length – the far-field constructors in farfield/farfield.jl derive their array rank from it, so a grid reporting a 1-tuple gets a Vector for free.
  • Base.enumerate(s): the coordinates in storage order, which must agree with the linear order of cartesiansamplepoints.
  • arraytype: the container a function sampled on this grid lives in.
  • cartesiansamplepoints: (k̂, weights), both shaped like size(s).
  • mirrorindices: the linear-index permutation realizing k̂ → -k̂.
  • cutoffparameter: the degree this grid integrates exactly, i.e. its bandwidth.

Base.eltype comes free from the type parameter.

See also

AbstractSphericalSampling, SphericalSampling.

source
MLFMA.Sampling.AbstractSphericalSampling — Type
AbstractSphericalSampling{T<:Number} <: AbstractSampling{T}

An AbstractSampling whose directions form a product grid over the two spherical coordinates: Nθ values of θ crossed with Nφ values of φ, stored [φ, θ] with φ contiguous.

Nθ, Nφ, two-index getindex, global-index arithmetic and length = Nθ·Nφ require this rectangular structure. Non-product grids do not inherit these methods.

The concrete grid chooses the θ nodes and quadrature rule: SphericalSampling places Gauss-Legendre nodes in θ, MLFMA.Equidistant.EquidistantSampling places midpoint nodes. Code that relies on a particular rule, such as local θ interpolation, must name the concrete type.

Required interface

Everything AbstractSampling requires, plus:

  • Nθ / Nφ: the two rates. Read off s.Nθ / s.Nφ by default.
  • θs / φs: the node vectors.
  • θ(s, i) / φ(s, j): single nodes, with whatever out-of-range continuation the grid defines.
  • sphericalsamplepoints: (k̂, weights) with k̂ in spherical coordinates.

length, θsφs, the two-index getindex and θφindicesfromglobalindex then follow from Nθ/Nφ and are provided here.

MLFMA.Sampling.CircularSampling — Type
CircularSampling{T}(Nφ)

Equidistant sampling of the unit circle: Nφ planar directions with no θ coordinate.

φⱼ = 2π(j - 1)/Nφ    j = 1 … Nφ        (`Nφ` even, so φ → φ+π is a half-array shift)

Nφ must be even for the same reason EquidistantSampling requires it: the antipodal map φ → φ + π is then exactly the index shift j → j + Nφ÷2, so mirrorindices is a permutation with no interpolation. An odd Nφ would put the half-turn between samples and make the mirror lossy.

Quadrature

Uniform weights 2π/Nφ – the trapezoidal rule on a periodic interval, which is spectrally accurate and exact for every Fourier mode e^{imφ} with |m| < Nφ. The circle's line element is dφ, so it needs neither the spherical sin θ Jacobian nor pole reflections.

Bandwidth

cutoffparameter(s) == Nφ÷2 - 1, the exact inverse of NφCircular. See that function for why the product of two degree-L patterns is what sets the rate.

See also

AbstractSampling, whose interface this implements in full; SphericalSampling, the 3-D counterpart.

MLFMA.Sampling.SphericalSampling — Type
struct SphericalSampling{T<:Number} <: MLFMA.AbstractSphericalSampling{T}

Gauss-Legendre sampling on (0, π) in θ and equidistant sampling on [0, 2π) in φ. Quadrature assumes periodicity in φ. Interpolation assumes the following continuation:

\[ f(θ, φ) = f(θ, φ + 2π), for φ < 0, f(θ, φ) = f(θ, φ - 2π), for φ ≥ 2π, f(θ, φ) = ±f(-θ, φ + π), for θ ≤ 0, 0 ≤ φ < π, f(θ, φ) = ±f(-θ, φ - π), for θ ≤ 0, π ≤ φ < 2π, f(θ, φ) = ±f(2π - θ, φ + π), for θ ≥ π, 0 ≤ φ < π, f(θ, φ) = ±f(2π - θ, φ - π), for θ ≥ π, π ≤ φ < 2π,\]

These rules apply to functions sampled on SphericalSampling.

Fields

  • Nθ::Int: Number of θ values.
  • Nφ::Int: Number of φ values.

Node vectors and θ weights are computed by θs, φs and wθs; they are not stored fields.

Usage

using MLFMA
using Test

sampling = MLFMA.SphericalSampling{Float64}(10, 20)
@show arraytype = MLFMA.arraytype(sampling){Float64}
k_cart, integrationweights = MLFMA.cartesiansamplepoints(sampling)
k_spherical, integrationweights = MLFMA.sphericalsamplepoints(sampling)

@test MLFMA.Nθ(sampling) == 10
@test MLFMA.Nφ(sampling) == 20

# f(θ, φ) = θ
f(x) = x[2]
fsampled = arraytype(undef, size(sampling))
fsampled .= f.(k_spherical)

result = sum(fsampled .* integrationweights)
@test result ≈ 2 * π^2

# first θ value and second φ value
@show sampling[1, 2]

# wrapping around is also included for indices <0 and >Nθ, Nφ
@show sampling[-1, 25]

# get f at the first θ value and first φ value
@show fsampled[1, 1, sampling]

# here we also support wrapping indices
@show fsampled[-1, 25, sampling]

MLFMA.Sampling.NφCircular — Method
NφCircular(cutoffparameter) -> Int

The number of circular directions needed to carry a pattern of degree L: 2(L + 1).

The 2-D analogue of NθNφ. The trapezoidal rule on [0, 2π) with Nφ points is exact for every mode |m| < Nφ. The translation integrand is a product of the degree-L translation operator and a degree-L pattern, so it carries content out to 2L, and 2L < Nφ needs Nφ ≥ 2L + 1. Rounding up to the next even value gives 2L + 2 = 2(L + 1), which is both the minimum that works and an exact inverse of cutoffparameter on this grid.

This differs from NθNφ's φ rate, 4(L + 1), which includes extra samples for spherical θ interpolation stencils. Circular interpolation does not need them.

MLFMA.Sampling.angularpermutation — Function
angularpermutation(sampling, symmetry) -> Vector{Int32}

The index permutation π with k̂[π[j]] == symmetry * k̂[j] for every sample of sampling.

Materialized rather than computed inline in the translation kernel. Measured at 0.82-0.83x the cost of the equivalent inline index arithmetic in an identical loop, and the storage is one vector per (symmetry, level), shared by every translation at that level – roughly 1% of what the translation reduction saves. Int32 because no angular grid this is used on approaches 2^31.

This is the permutation of symmetry itself. A translation kernel holding the canonical translation for q == applysymmetry(S, canonical) needs T(k̂, q) == T(S⁻¹k̂, canonical) and therefore wants the permutation of inversesymmetry(S). The two differ for every element that is not its own inverse; the antipodal map is its own inverse and cannot detect the confusion.

Raises rather than approximating when symmetry does not map the grid onto itself.

source
MLFMA.Sampling.angularpermutation — Method
angularpermutation(s::SphericalSampling, symmetry)

A symmetry fixing the polar axis factors into an independent action on θ and on φ, and this is the product of the two index maps.

blockdiag(A, s₃) sends k̂ = (sinθ cosφ, sinθ sinφ, cosθ) to (sinθ · A(cosφ, sinφ), s₃ cosθ). The third component gives θ → θ for s₃ = +1 and θ → π - θ for s₃ = -1; the first two give φ → σφ + β exactly as in two dimensions. The two do not interact, because sin(π - θ) == sin θ leaves the equatorial factor's magnitude alone.

θ → π - θ is an exact index reversal because Gauss-Legendre nodes are symmetric about the midpoint: θᵢ and θ_{Nθ+1-i} are reflections of each other. Without that quadrature symmetry, these elements would require interpolation and could not be used for reduction.

cartesiansamplepoints(s::CircularSampling) -> (k̂, weights)

The unit direction and integration weight at every sample, both Nφ-vectors.

MLFMA.Sampling.samplingrate — Method
samplingrate(::CircularSamplingBuilder, cutoffparameter)

One rate, not two – see NφCircular for the exactness rule and MLFMA.samplingrate for why it lives on the builder.

The rate is rounded up to a multiple of four, beyond the exactness requirement. φ → φ + π/2 lands on a grid point only when Nφ ≡ 0 (mod 4), allowing full square symmetry. Over the 40 distinct far-field offsets at one level, this permits a 5.71x reduction rather than 2.00x. NφCircular gives 2(L + 1), a multiple of four only for odd L. The tree uses one common group for all levels, so a single even-L level would otherwise limit the map to 2.00x.

Rounding adds two directions on even-L levels and none on odd ones, i.e. 1/(L + 1) relatively. Measured: +33 % at L = 2, +20 % at L = 4, +14 % at L = 6, +11 % at L = 8, falling to +5 % by L = 20. The worst case is the smallest box, and it is paid by every 2-D map rather than only by those using the reduction.

Rounding is independent of the translation collection. Both reduced and unreduced collections use the same grid, so their numerical results can be compared directly.

NφCircular remains the exactness threshold. MLFMA.CircularHarmonics uses that threshold with its own oversampling factor, independent of this rounding.

As a consequence, cutoffparameter(grid) == Nφ ÷ 2 - 1 returns L + 1 on a rounded level, so the translation operator is built one degree higher than the rate rule asked for. That is safe – exactness needs 2(L + 1) < 2L + 4 – and slightly more accurate, but it means cutoffparameter ∘ samplingrate is no longer the identity, only ≥.

MLFMA.Sampling.supportedsymmetry — Method
supportedsymmetry(s::SphericalSampling)

The order-16 subgroup fixing the polar axis, for a symmetric rule in θ and a uniform rule in φ whose rate supports quarter turns.

The full order-48 group includes elements that carry the polar axis into the equatorial plane. The θ×φ grid is not closed under those rotations: θ uses Gauss-Legendre nodes and φ is uniform.

Within the subgroup the two factors are independent, so the action is a permutation. Such a symmetry is blockdiag(A, ±1) with A a 2x2 signed permutation, so it sends θ → θ or π - θ and, separately, φ → σφ + β. sin(π - θ) == sin θ, so the φ factor does not depend on which θ case holds.

The φ quarter turns need Nφ % 4 == 0, which NθNφ always delivers (Nφ = 4(L+1)), so the fallback below is unreachable through the rate rule. It exists so a hand-built sampling gets a smaller group rather than a wrong one.

MLFMA.Sampling.θs — Method
θs(s::SphericalSampling{T}) -> Vector{T}

The polar sample positions, in radians on [0, π].

These are Gauss-Legendre nodes mapped from [-1, 1] to [0, π], not nodes in cos θ. The integration weights include the sin θ Jacobian separately. The φ nodes are equispaced and periodic (see φs).

Returned in the sampling's own element type, and computed on each call rather than stored.
