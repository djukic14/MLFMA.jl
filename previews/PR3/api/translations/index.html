Translations

Diagonal I2O translation, and its symmetry-reduced form.

MLFMA.Translations — Module
MLFMA.Translations

The translation operators that move a far field from one box to another at the same level, and the collections that store them.

Defines MLFMATranslator, plain and symmetry-reduced I2O collections, and the dummy collection for an empty level range. Sampling supplies the symmetry policies and angular permutations.

source
MLFMA.Sampling.supportedsymmetry — Method
supportedsymmetry(samplings::AbstractVector, ::Val{D})

Return the largest symmetry policy supported exactly by every level's grid.

Per-level policies can differ – CircularSampling's quarter turns need Nφ % 4 == 0, and the rate rule does not guarantee that at every level – and the tree is canonicalized once, with one policy, for all of them. So the common choice is the smallest group among the levels.

Choosing by group order relies on the policies forming a chain under inclusion. SymmetryTranslationCollection validates the choice by building every element's angular permutation at every level. angularpermutation raises if the grid cannot apply an element exactly.

source
MLFMA.Translations.SymmetryTranslationCollection — Method
SymmetryTranslationCollection(γ, tree, translatingplan, translationsamplings; levelscales, verbose)

Drop-in replacement for TranslationCollection that builds one translation per symmetry orbit instead of one per direction.

Select it through the strategy:

strategy = MLFMA.MLFMAStrategy(
    operator,
    space;
    i2ostrategy=MLFMA.I2OTranslationStrategy(;
        TranslationCollection=MLFMA.SymmetryTranslationCollection
    ),
)

Symmetry acts by an exact grid permutation, with no interpolation or additional approximation. Rounding can differ from the unreduced collection because the inputs are rotated. The 2-D single-layer fixture agreed to ~1e-14 relative in both couplings and matvec; see the header.

MLFMA.Translations.TranslationCollection — Method
TranslationCollection(γ, tree, translatingplan, translationsamplings; levelscales, verbose=false)
TranslationCollection(γ, tree, aggregationplan, disaggregationplan, translationsamplings; ...)

Build the MLFMA interpolation-to-observation translation operators for a tree.

This builder returns an H2Factory.I2OTranslationCollection wrapping an MLFMATranslator, tagged H2Trees.DirectionInvariancePerLevel(). There is no TranslationCollection struct to dispatch on.

The four-argument form takes a ready translating plan. The five-argument form is the Petrov-Galerkin entry: it combines the trial-side aggregation and test-side disaggregation plans into one translating plan and delegates, mirroring H2Factory.I2OTranslationCollection's own convenience wrapper.

With no translation samplings it delegates to DummyTranslationCollection.

The directions come from the sampling and keep its element type. They are not forced to SVector{3}, because a CircularSampling yields SVector{2}; and not converted to real(T) from γ, because the grid owns its own precision.

MLFMA.Translations.translationoperator! — Method
translationoperator!(
    translationoperator::AbstractArray{T1},
    γ::T1,
    cartesiansamplepoints::AbstractArray{SVector{D,T}},
    originalcenter::SVector{D,T},
    newcenter::SVector{D,T},
    cutoffparameter::Int,
)

Compute the translation function between two points in space.

Arguments

  • translationoperator: The destination array for the translation operator.
  • γ: im * wavenumber.
  • cartesiansamplepoints: Cartesian sample directions as an array of SVector{D,T}.
  • originalcenter: The original center point.
  • newcenter: The new center point.
  • cutoffparameter: The requested truncation order.

Returns

  • The truncation order used. The operator values are written into translationoperator.
