MLFMA.jl

MLFMA builds fast matrix-vector products for wave-kernel matrices. It uses BEAST to assemble boundary-element operators, H2Trees to group basis functions, and H2Factory to run the hierarchical multiplication.

Construct a map, or start with far fields and directions to see how the method works.

From an integral to three small operations

For example, a scalar single-layer boundary-element matrix contains integrals

\[A_{ij}=\int_\Gamma\int_\Gamma v_i(x)\,\frac{e^{-\mathrm{i}k|x-y|}}{4\pi|x-y|}\,u_j(y)\,\mathrm{d}y\,\mathrm{d}x.\]

For well-separated test and trial boxes, MLFMA approximates this block by

\[A_{ij}\approx\sum_q w_q\,V_i(\widehat k_q)\, T_{ab}(\widehat k_q)\,U_j(\widehat k_q).\]

U is the trial function's radiation pattern, T translates between box centers, and V is the test function's receive pattern. Their phase conventions and normalization belong together. The weights w integrate over directions. Vector operators use component-valued patterns and the operator's component coupling.

Trial coefficients→Radiation
U x→Translation
T .* field→Reception
Vᵀ field→Tested values

The tree lets many functions share these operations. I2I transfers combine children into parents; O2O transfers pass incoming fields back to children. Near blocks are assembled directly. The H2Factory guide explains the traversal, core/workspace split and scheduling.
