Seams

The joins between layers.

MLFMA.Seams — Module
MLFMA.Seams

Shared function declarations for calls from lower layers to higher ones.

Far-field kernels call these functions; Operators and Assembly supply the methods. This module contains no implementations, types or policy tables. Builders belong in Assembly, where they can use operator properties directly.

source
MLFMA.Seams.farfieldtype — Function
farfieldtype(operator)

Return the far-field representation type for operator, such as scalar or tangential-spherical. Equal component counts do not imply equal representations.

Operators defines the table; Assembly and the dummy assembler add methods.

source
MLFMA.Seams.radiationfieldcollectiontype — Function
radiationfieldcollectiontype(operator)

Return the radiation-field collection type for operator.

LazyReceiveFieldCollection uses it to check the wrapped representation, not just its component count.

source
MLFMA.Seams.receivecouplingrule — Function
receivecouplingrule(operator, ::Type{<:AbstractFarField})

Return the component-mixing rule from radiation to receive fields.

The rule uses the component indices of the supplied far-field representation. Lazy receive kernels and harmonic collections call it; Operators defines the rules.
